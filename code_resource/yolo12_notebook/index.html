YOLOv12 Training Code

A step-by-step guide to setting up the environment, dataset, and training a YOLOv12 model.

Phase 1: Environment Preparation (Setup)

Before working, we must first prepare the work environment. Think of it like setting up a table and equipment before starting to cook. There are three steps: check the machine, prepare the folder, and install the equipment (library).

1.1. Check GPU Availability

A GPU is a very fast, specialized "brain" for training AI. The command below checks whether we have access to a GPU. The ! at the beginning indicates that this is a system command, not regular Python code. Simply run this cell and see if any lines contain the GPU name (e.g., Tesla T4).

!nvidia-smi

1.2. Define Work Folder (HOME)

We'll use a variable called HOME as the "address" of the folder where all data and results are stored. os.getcwd() means get current working directory = view the folder we're currently in. 

import os
HOME = os.getcwd()
print(HOME)

1.3. Install Required Libraries

Library is a collection of ready-to-use code written by others, so that we don't have to write everything from scratch. Here we install:

  • ultralytics — the main tool for using and training YOLO.
  • supervision — a helper tool for processing detection results.
  • roboflow — a tool to download datasets (images + labels) from Roboflow.

The %pip install line tells Python to install them. This only needs to be run once.

%pip install -q "ultralytics>=8.4.0" supervision roboflow

# prevent ultralytics from tracking your activity
!yolo settings sync=False
import ultralytics
ultralytics.checks()

Phase 2: Preparing the Dataset for Fine-Tuning

Dataset is a collection of images along with annotations (labels) of object locations within the images. The model learns from this dataset.

We download the dataset from Roboflow Universe (a collection of public datasets). When the program asks for an authentication token, follow the instructions:

  1. Open the link that appears and log in to your Roboflow account.
  2. Copy the token, then paste it into the input box and press Enter.
!mkdir {HOME}/datasets
%cd {HOME}/datasets

from google.colab import userdata
import roboflow

roboflow.login()
rf = roboflow.Roboflow()

project = rf.workspace("").project("")
version = project.version()
dataset = version.download("yolov12")
