# Cara Menyiapkan GDevelop dan Aset Pixel Adventure untuk Game Platformer Pertamamu

GDevelop adalah game engine _no-code_ yang ramah untuk pemula. Di tutorial ini, kita belum masuk ke pembuatan gameplay, tetapi menyiapkan fondasi proyek: aplikasi, aset, folder kerja, dan pengaturan grid.

Ikuti setiap langkah sambil menonton video yang disematkan. Jika penyimpanan laptop penuh atau GDevelop tidak bisa diunduh, kamu bisa memakai versi web.

## Yang Perlu Disiapkan

- Laptop/PC dengan Windows, macOS, atau Linux — atau browser modern.
- Koneksi internet.
- Akun Google untuk versi web.
- Ruang penyimpanan yang cukup.
- Estimasi waktu: 20–30 menit.

## 1. Unduh GDevelop

1. Buka Google, cari **GDevelop**, atau langsung kunjungi **gdevelop.io**.
2. Pilih menu **Download**.
3. Unduh sesuai sistem operasi yang kamu miliki: Windows, macOS, atau Linux.
4. Jika memori laptop penuh atau tidak bisa mengunduh, klik tombol **Launch** untuk memakai versi web.

🎬 **Video:** [Embed video unduh GDevelop]

> Catatan: Pengguna versi web wajib login terlebih dahulu. Agar lebih nyaman, gunakan **Login with Google**.

## 2. Install dan Buka GDevelop

1. Buka file installer yang sudah diunduh.
2. Ikuti proses instalasi sampai selesai.
3. Buka aplikasi GDevelop.

> Jika muncul peringatan keamanan, izinkan aplikasi berjalan.

## 3. Unduh Aset Pixel Adventure

1. Cari **platformer game assets** di Google.
2. Pilih aset **Pixel Adventure** — umumnya berasal dari Pixel Frog.
3. Unduh file aset tersebut. Biasanya file berbentuk ZIP.

🎬 **Video:** [Embed video unduh aset]

> Catatan: Perhatikan lisensi aset. Jika ingin dipakai untuk proyek komersial, cek ketentuan dari pembuat aset.

## 4. Ekstrak Aset

1. Temukan file ZIP hasil unduhan.
2. Ekstrak file tersebut:
   - **Windows:** klik kanan ZIP > **Extract All**.
   - **macOS:** klik dua kali file ZIP.
3. Tunggu sampai proses ekstrak selesai.

🎬 **Video:** [Embed video extract aset]

4. Hapus file ZIP jika sudah selesai diekstrak.

## 5. Rapikan Aset ke Folder Baru

1. Buat folder baru, misalnya **Aset Pixel Adventure**.
2. Letakkan hasil ekstrak aset ke dalam folder tersebut.
3. Simpan folder di lokasi yang mudah ditemukan, misalnya di **Documents/GDevelop**.

> Tidak ada aturan penamaan folder. Yang penting mudah diingat dan tidak dipindah-pindah.

## 6. Buat Proyek Baru di GDevelop

1. Buka GDevelop.
2. Klik **Create New Project** atau **New Project**.
3. Pilih konfigurasi seperti pada video.
4. Beri nama proyek, misalnya **Platformer Pertama**.
5. Tentukan lokasi penyimpanan proyek.

🎬 **Video:** [Embed video buat new project]

> Pengguna versi web: login dulu, lalu gunakan **Login with Google** agar proyek tersimpan dengan aman.

## 7. Atur Grid dan Tampilan Canvas

1. Buka scene proyek.
2. Klik pengaturan grid di toolbar canvas.
3. Sesuaikan **ukuran grid** dan aktifkan opsi **tampilkan grid** seperti pada video.
4. Contoh: jika aset bertile 16×16, gunakan grid 16. Jika 32×32, gunakan grid 32.

🎬 **Video:** [Embed video edit grid]

## Tips Navigasi Canvas GDevelop

- **Zoom in / zoom out:** scroll up / scroll down.
- **Geser atas–bawah:** tahan **Shift** sambil scroll.
- **Geser kiri–kanan:** tahan **Alt** atau **Option** di Mac sambil scroll.
- **Mouse:** tahan **Space** sampai muncul ikon tangan, lalu klik kiri dan geser.

## Jika Ada Kendala

- **Tidak bisa mengunduh GDevelop:** gunakan versi web lewat tombol **Launch**.
- **Versi web tidak bisa menyimpan:** pastikan sudah login dengan Google.
- **ZIP tidak bisa diekstrak:** gunakan 7-Zip/WinRAR atau fitur bawaan OS.
- **Aset tidak muncul:** pastikan file sudah diekstrak, bukan masih di dalam ZIP.
- **Grid tidak terlihat:** aktifkan opsi **Show Grid**.
- **Proyek hilang:** simpan manual dan cek koneksi jika memakai versi web.

## Penutup

Selamat! Kamu sudah menyiapkan GDevelop, aset, proyek baru, dan grid. Langkah selanjutnya adalah mengimpor aset ke GDevelop, membuat objek sprite, menambahkan behavior **Platformer**, dan menyusun level dengan tilemap.
