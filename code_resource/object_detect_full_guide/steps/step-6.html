Menghubungkan dataset yang telah dibuat langsung ke Google Colab menggunakan Roboflow Python SDK memudahkan proses training tanpa perlu mengunduh dan mengunggah file dataset besar secara manual.

Tahapan Pelaksanaan:

  1. Buka Versi Dataset yang Telah Dibuat: Pada dashboard versi dataset Anda, klik tombol Export Dataset atau Download Dataset.
  2. Pilih Format Ekspor: Pilih format model yang ingin Anda gunakan untuk training (misal: YOLOv8, YOLOv11, atau YOLOv5 PyTorch).
  3. Pilih "Show download code": Pilih opsi tampilan kode untuk Terminal / Jupyter / Colab.
  4. Salin Snippet Kode: Salin baris kode Python yang disediakan oleh Roboflow.
  5. Tempel di Google Colab: Buka notebook Google Colab Anda, tambahkan code cell baru, lalu paste snippet tersebut dan jalankan cell untuk mengunduh dataset ke workspace runtime Colab.
Snippet Contoh Kode:
!pip install roboflow
from roboflow import Roboflow
rf = Roboflow(api_key="YOUR_API_KEY")
project = rf.workspace("workspace-id").project("project-id")
version = project.version(1)
dataset = version.download("yolov8")
