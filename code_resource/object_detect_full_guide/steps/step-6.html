Menghubungkan dataset yang telah dibuat langsung ke Google Colab memudahkan proses training model object detection tanpa perlu mengunduh dan mengunggah file dataset secara manual ke komputer lokal.

Tahapan Menggunakan Dataset Roboflow di Google Colab:

  1. Simpan Salinan Notebook Google Colab:
    • Buka tautan Google Colab (Notebook YOLOv12).
    • Klik menu File di pojok kiri atas, lalu pilih Save a copy in Drive agar notebook tersimpan di Google Drive pribadi Anda dan dapat diedit.
  2. Buka Roboflow dan Unduh Kode Dataset:
    • Buka tab Roboflow pada versi dataset yang telah dibuat (Versions), lalu klik tombol Download Dataset di pojok kanan atas.
    • Pada jendela pop-up:
      • Pilih format anotasi yang sesuai (pada video dipilih YOLOv12).
      • Pada opsi Download Options, pilih Show download code, lalu klik Continue.
  3. Salin Kode Cuplikan (Snippet Code):
    • Pada tab Jupyter, salin baris kode konfigurasi proyek Roboflow Anda:
      project = rf.workspace("...").project("...")
      version = project.version(1)
      dataset = version.download("yolov12")
  4. Tempel Kode ke Google Colab:
    • Kembali ke tab notebook Google Colab salinan Anda (Copy of YOLO12...).
    • Gulir ke bagian Fase 2: Menyiapkan Dataset untuk Fine-Tuning.
    • Tempelkan (paste) baris kode yang telah disalin ke dalam sel kode tersebut untuk menggantikan nilai workspace dan project bawaan.
  5. Hubungkan Runtime dan Jalankan Notebook:
    • Klik tombol Connect di pojok kanan atas untuk menghubungkan runtime (menggunakan GPU T4).
    • Klik menu Run all (atau jalankan sel secara berurutan) untuk memulai seluruh proses persiapan lingkungan, pengunduhan dataset langsung dari Roboflow, hingga pelatihan model.
Catatan Penting:
  • Penyalinan Notebook (Save a copy in Drive): Langkah ini wajib dilakukan karena notebook asli berstatus hanya-baca (view-only). Menyalinnya ke Drive memungkinkan perubahan kode dan penyimpanan progres secara permanen.
  • Kesesuaian Format Anotasi: Format ekspor dataset pada Roboflow harus disesuaikan dengan arsitektur model yang digunakan di Colab (pada contoh ini menggunakan format YOLOv12).
  • Integrasi Tanpa Unduh Manual (Show Download Code): Memilih opsi Show download code memungkinkan Colab mengunduh dan mengekstrak dataset secara otomatis langsung dari server Roboflow ke direktori kerja Colab tanpa memakan ruang penyimpanan lokal komputer.
