Setelah gambar selesai diberi anotasi atau label, gambar tersebut harus dipindahkan dari antrean anotasi (Annotating Job) ke dalam kumpulan dataset utama proyek agar siap diproses pada pembuatan versi model.

Tahapan Pelaksanaan:

  1. Kembali ke Halaman Ringkasan Batch (Annotate Overview): Setelah selesai melabeli seluruh gambar, kembali ke halaman batch anotasi untuk memastikan semua data berstatus Annotated (pada video: 23 gambar teranotasi).
  2. Klik Tombol Penambahan ke Dataset: Klik tombol Add [Jumlah] Images To Dataset berwarna ungu di sudut kanan atas layar.
  3. Tentukan Metode Pembagian Data (Split Method): Pada jendela pop-up Add Images to Dataset, pilih metode pembagian data (secara default: Split Images Between Train/Valid/Test).
  4. Atur Rasio Pembagian (Train / Valid / Test): Sesuaikan bilah geser persentase alokasi data sesuai kebutuhan (pada video digunakan proporsi: 70% Train / 16 gambar, 20% Valid / 5 gambar, dan 10% Test / 2 gambar).
  5. Konfirmasi Penambahan Data: Klik tombol Add 23 Images di pojok kanan bawah pop-up dan tunggu proses Inserting Images to Dataset selesai.
  6. Periksa Data pada Menu Dataset: Buka menu Dataset pada bilah navigasi kiri untuk memverifikasi data yang telah berhasil masuk dan dikelompokkan.
Catatan Penting:
  • Filter Berdasarkan Subset (Split Filter): Pada menu Dataset, Anda dapat memfilter tampilan gambar berdasarkan kategori Train, Valid, atau Test untuk memastikan data terdistribusi sesuai proporsi yang diatur.
