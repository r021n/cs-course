Setelah gambar selesai diberi anotasi atau label, gambar tersebut harus dipindahkan dari antrean anotasi (Annotating Job) ke dalam kumpulan dataset utama proyek agar siap diproses pada pembuatan versi model.

Tahapan Pelaksanaan:

  1. Periksa Kelengkapan Anotasi: Pastikan seluruh gambar pada job pelabelan sudah berstatus 100% Annotated atau disetujui (Approved).
  2. Klik Tombol "Add approved images to Dataset": Pada sudut kanan atas tab Annotate, klik tombol untuk memproses penggabungan gambar terlabeli ke dataset utama.
  3. Konfirmasi Pembagian Dataset (Split): Tinjau ulang pembagian rasio antara Train, Valid, dan Test jika diminta.
  4. Selesaikan Penggabungan: Klik tombol konfirmasi dan tunggu beberapa saat hingga gambar dan label berhasil terindeks ke dalam dataset utama.
Catatan: Gambar yang belum dimasukkan ke dalam dataset utama tidak akan ikut diproses saat Anda men-generate versi dataset di langkah berikutnya.
