Setelah proyek dibuat, langkah selanjutnya adalah mengunggah kumpulan gambar (dataset) mentah yang akan digunakan untuk proses training, validasi, dan pengujian model.

Tahapan Pelaksanaan:

  1. Masuk ke Halaman Unggah Data: Buka proyek Anda di Roboflow dan pilih menu Upload Data pada bilah navigasi di sisi kiri.
  2. Pilih Berkas / Gambar: Klik tombol Select File(s) (atau Anda juga dapat memilih opsi Select Folder maupun langsung melakukan Drag and Drop berkas ke area yang disediakan).
  3. Pilih File dari Komputer: Pada jendela File Explorer, navigasikan ke folder tempat gambar disimpan, pilih file yang ingin diunggah (pada video dipilih 23 file foto), lalu klik Open.
  4. Proses dan Verifikasi Pratinjau: Tunggu sejenak saat sistem menjalankan proses pembacaan file (Processing files...). Setelah pratinjau gambar muncul dan jumlah gambar terverifikasi, klik tombol Save and Continue di pojok kanan atas.
  5. Menunggu Proses Pengunggahan (Uploading Files): Tunggu proses pengunggahan selesai. Setiap gambar yang berhasil diunggah akan ditandai dengan ikon centang.
  6. Selesai dan Lanjut ke Tahap Pelabelan: Setelah semua gambar selesai diunggah, halaman akan otomatis diarahkan ke menu Unassigned Images untuk langkah anotasi/pelabelan data selanjutnya.
Catatan Penting

Format File yang Didukung (Supported Formats):

  • Gambar (Images): Mendukung format .jpg, .png, .bmp, .webp, dan .avif.
  • Anotasi (Annotations): Mendukung 26 format anotasi (jika sudah memiliki anotasi sebelumnya).
  • Video: Mendukung format .mp4, .mov, dan .avi.
  • Dokumen: Mendukung format .pdf.
