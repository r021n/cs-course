Autentikasi akun Roboflow di Google Colab menggunakan token interaktif memungkinkan akses aman untuk mengunduh dataset tanpa perlu menuliskan API Key secara langsung di dalam kode.

Tahapan Mendapatkan dan Menggunakan Token Roboflow di Google Colab:

  1. Jalankan Sel Kode Fase 2 (Setup Dataset): Jalankan sel kode yang memuat fungsi roboflow.login() dan inisialisasi dataset hingga muncul tautan autentikasi dan kolom input token pada keluaran (output) sel.
  2. Buka Tautan Autentikasi CLI: Klik tautan https://app.roboflow.com/auth-cli yang tertera pada pesan keluaran (atau salin dan buka di tab baru peramban).
  3. Salin Kunci Token dari Roboflow: Pada halaman Authorize Your Roboflow CLI, klik ikon salin (copy to clipboard) di samping deretan kode token autentikasi.
  4. Tempel Token ke Google Colab: Kembali ke tab Google Colab, tempelkan (paste) kode token ke dalam kotak isian bertuliskan Paste the authentication token here:.
  5. Tekan Enter untuk Memvalidasi: Tekan tombol Enter pada keyboard untuk mengirimkan token. Sistem akan memuat workspace, memverifikasi proyek, lalu mengunduh (downloading) dan mengekstrak dataset secara otomatis.
Catatan Penting:
  • Metode Login Interaktif: Fungsi roboflow.login() mengamankan akun tanpa perlu menuliskan API Key secara langsung (hardcoded) di dalam sel kode publik atau repositori bersama.
