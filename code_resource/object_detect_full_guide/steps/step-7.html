Token atau Private API Key digunakan untuk mengautentikasi akun Roboflow Anda saat mengunduh dataset private atau mengakses fitur Roboflow secara terprogram dari script eksternal.

Tahapan Pelaksanaan:

  1. Buka Pengaturan Akun (Settings): Klik ikon profil atau nama workspace di pojok kanan atas, lalu pilih Settings.
  2. Masuk ke Menu Roboflow API: Pilih opsi Roboflow API atau API Keys pada menu navigasi akun.
  3. Salin Private API Key: Temukan bagian Private API Key Anda dan klik tombol Copy.
  4. Gunakan Token di Colab / Script: Masukkan token API key tersebut ke dalam kode Python (pada parameter Roboflow(api_key="...")) atau tempelkan pada prompt terminal yang meminta token.
  5. Eksekusi Autentikasi: Jalankan cell untuk memverifikasi autentikasi. Setelah berhasil, dataset akan otomatis diunduh dan diekstrak ke folder proyek di Google Colab.
Keamanan Token: Jaga kerahasiaan Private API Key Anda. Jangan mempublikasikan token ini ke repository publik (misalnya GitHub publik) untuk mencegah akses data yang tidak diotorisasi.
