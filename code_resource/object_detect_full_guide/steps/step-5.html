Membuat versi dataset (Dataset Version) adalah langkah membekukan (freeze) kondisi dataset saat ini dengan menerapkan opsi preprocessing dan augmentasi data sebelum digunakan untuk proses training model.

Tahapan Pelaksanaan:

  1. Buka Menu Generate: Navigasikan ke tab Generate atau Versions pada menu samping kiri.
  2. Tinjau Dataset Health: Periksa ringkasan distribusi data seperti jumlah gambar, rasio pembagian (Train/Valid/Test), dan distribusi kelas label.
  3. Konfigurasi Preprocessing: Tentukan langkah pra-pemrosesan seperti Auto-Orient dan standarisasi ukuran gambar (misal: Resize ke 640x640).
  4. Tambahkan Augmentasi (Opsional): Tambahkan augmentasi seperti flip horizontal, rotasi, perubahan kecerahan (brightness), atau blur untuk melipatgandakan variasi data training.
  5. Generate Version: Klik tombol Generate untuk membuat snapshot versi dataset permanen (misalnya Version 1).

Tips Konfigurasi:

  • Gunakan ukuran resize standar (seperti 640x640) yang paling optimal untuk arsitektur model YOLO.
  • Hindari augmentasi ekstrem (misal flip vertikal pada objek mobil atau teks) jika orientasi tersebut tidak mungkin terjadi di dunia nyata.
