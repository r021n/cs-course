Membuat versi dataset (Dataset Version) adalah langkah membekukan (freeze) kondisi dataset saat ini dengan menerapkan opsi preprocessing dan augmentasi data sebelum digunakan untuk proses training model.

Tahapan Pelaksanaan:

  1. Buka Menu Versions: Pilih menu Versions pada bilah navigasi di sebelah kiri.
  2. Periksa Pembagian Data (Train/Test Split): Pastikan rasio pembagian dataset pada tahap awal sudah sesuai (pada video: 16 data training, 5 data validation, dan 2 data testing).
  3. Konfigurasi Tahap Pemrosesan Awal (Preprocessing): Klik + Add Preprocessing Step untuk menambahkan teknik prapemrosesan gambar yang diinginkan:
    • Auto-Orient: Diterapkan secara default.
    • Resize: Mengubah ukuran resolusi gambar (pada video dipilih Stretch to 512x512), lalu klik Apply.
    • Grayscale: Mengubah semua kanal warna gambar menjadi hitam-putih/skala abu-abu, lalu klik Apply.
    • Setelah selesai, klik tombol Continue.
  4. Konfigurasi Tahap Augmentasi (Augmentation): Klik + Add Augmentation Step untuk menambah variasi data latih (training set):
    • Rotation: Menambahkan variasi rotasi sudut (pada video diatur antara -15° dan +15°), lalu klik Apply.
    • Shear: Menambahkan distorsi perspektif (pada video diatur ±10° Horizontal dan ±10° Vertikal), lalu klik Apply.
    • Grayscale: Menerapkan efek abu-abu pada sebagian data latih secara probabilistik (pada video diatur Apply to 15% of images), lalu klik Apply.
    • Setelah selesai, klik tombol Continue.
  5. Tentukan Pengali Augmentasi (Augmentation Multiplier) & Buat Versi:
    • Pilih faktor kelipatan data pada menu dropdown Augmentation Multiplier (pada video dipilih 3x sehingga total bertambah menjadi 55 gambar).
    • Masukkan catatan versi pada kolom version notes jika diperlukan.
    • Klik tombol Create di bagian bawah.
  6. Selesai dan Siap Dilatih: Tunggu proses Initializing version... selesai hingga muncul ringkasan dataset version baru yang siap digunakan untuk proses Train Model.
Catatan Penting:
  • Tujuan Preprocessing: Teknik prapemrosesan (seperti Resize dan Grayscale) berfungsi untuk mengurangi waktu pelatihan (training time) serta mempercepat kinerja inferensi (inference speed) model.
  • Tujuan Augmentasi: Augmentasi hanya diterapkan pada Training Set guna memperkaya variasi sampel dan melatih ketahanan model terhadap perubahan sudut kamera atau orientasi objek tanpa mengubah data validasi/tes.
