Langkah awal dalam membuat model object detection adalah menginisialisasi workspace dan menentukan jenis proyek pada Roboflow sesuai dengan kebutuhan pendeteksian target objek.

Tahapan Pelaksanaan:

  1. Masuk / Login ke Roboflow: Akses situs roboflow.com dan klik tombol Sign In di pojok kanan atas untuk masuk ke dashboard/workspace.
  2. Buka Menu Projects: Pada bilah navigasi (sidebar) sebelah kiri, pilih menu Projects.
  3. Buat Proyek Baru: Klik tombol + New Project yang terletak di bagian kanan atas halaman.
  4. Konfigurasi Detail Proyek (Create Project):
    • Project Name: Masukkan nama proyek yang diinginkan (pada video dicontohkan: eyeglass).
    • Visibility: Pilih tingkat visibilitas proyek (Public atau Private).
    • Licenses: Tentukan lisensi dataset (contoh: CC BY 4.0).
    • Tool: Pilih metode/alat anotasi (pada video dipilih Traditional).
    • Project Type: Pilih tipe Object Detection (Identify objects and their positions with bounding boxes).
  5. Konfirmasi Pembuatan Proyek: Klik tombol Create Public Project di bagian bawah untuk membuat dan mengaktifkan proyek.
  6. Tahap Upload Dataset: Setelah proyek berhasil dibuat, sistem akan otomatis mengarahkan ke halaman Upload Data untuk mengunggah gambar atau data yang akan dianotasi.
Catatan Penting:
  • Pilihan Jenis Proyek (Project Type): Roboflow menyediakan berbagai jenis tugas Computer Vision (seperti Classification, Instance Segmentation, dan Keypoint Detection). Pastikan memilih Object Detection jika target model menggunakan deteksi berbasis kotak batas (bounding box).
