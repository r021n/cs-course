Anotasi atau pelabelan adalah proses krusial untuk memberikan informasi letak dan kelas objek kepada model pembelajaran mesin melalui bounding box (kotak pembatas).

Tahapan Pelaksanaan:

  1. Buka Menu Annotate: Masuk ke tab Annotate dan klik pada batch gambar yang belum diberi label (Unannotated).
  2. Gunakan Tool Bounding Box: Pilih tool kotak pembatas pada toolbar atau tekan shortcut keyboard W.
  3. Tarik Kotak Mengelilingi Objek: Klik dan seret kursor tepat mengelilingi seluruh area objek yang ingin dideteksi.
  4. Pilih / Beri Nama Label Kelas: Tulis atau pilih nama label yang sesuai dengan objek di dalam kotak (contoh: person, car).
  5. Ulangi untuk Seluruh Objek: Jika dalam satu gambar terdapat lebih dari satu objek, tandai semua objek tersebut.
  6. Lanjut ke Gambar Berikutnya: Tekan tombol panah kanan atau shortcut keyboard untuk menyimpan dan berpindah ke gambar selanjutnya hingga seluruh dataset terlabeli 100%.
Prinsip Pelabelan yang Baik:
• Tight Bounding Box: Kotak harus memuat seluruh bagian objek tanpa menyisakan terlalu banyak ruang kosong (margin).
• Konsistensi: Jika memberi label bagian tertentu (misal helm atau roda), pastikan konsisten di seluruh gambar dataset.
• Objek Terpotong (Occlusion): Jika objek terhalang sebagian namun masih dapat dikenali, tetap buat kotak pembatas pada area objek yang terlihat.
