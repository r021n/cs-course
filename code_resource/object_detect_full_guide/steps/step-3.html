Anotasi atau pelabelan adalah proses krusial untuk memberikan informasi letak dan kelas objek kepada model pembelajaran mesin melalui bounding box (kotak pembatas).

Tahapan Pelaksanaan:

  1. Pilih Metode Pelabelan Manual: Pada halaman Unassigned Images, klik opsi Label Manually pada panel sebelah kanan untuk membuat sesi tugas pelabelan (labeling job).
  2. Mulai Sesi Anotasi: Pada halaman ringkasan tugas (job dashboard), klik tombol Start Annotating di pojok kanan atas untuk masuk ke antarmuka editor gambar.
  3. Pilih Alat Bounding Box: Pilih ikon Bounding Box Tool (tools nomor 2 dari atas) pada bilah alat (toolbar) di sisi kanan (atau tekan pintasan keyboard B).
  4. Tandai Objek Sasaran: Klik dan seret (drag) kursor untuk membuat kotak pembatas (bounding box) yang membungkus objek secara presisi (pada video: objek kacamata).
  5. Beri Nama dan Simpan Kelas (Class): Pada jendela Annotation Editor yang muncul, ketik nama kelas objek (contoh: eyeglass), lalu klik Create Class "eyeglass" atau klik tombol simpan.
  6. Pindah ke Gambar Berikutnya: Klik tombol panah kanan (Next Image) pada bilah navigasi atas untuk melanjutkan ke gambar berikutnya.
  7. Ulangi Pelabelan pada Seluruh Gambar: Buat bounding box pada setiap gambar berikutnya, lalu cukup klik nama kelas yang telah tersimpan (eyeglass) tanpa perlu mengetik ulang. Ulangi proses ini hingga semua gambar (23 gambar) selesai dianotasi.
  8. Tinjau Kembali Hasil Anotasi: Gunakan tombol panah navigasi kiri/kanan untuk memeriksa ulang ketepatan letak dan ukuran bounding box pada seluruh gambar.
Catatan Penting:
  • Pembuatan/Pemilihan Kelas: Kelas baru hanya perlu dibuat satu kali di awal. Untuk gambar-gambar berikutnya, kelas tersebut akan muncul di daftar pilihan cepat pada pop-up Annotation Editor.
